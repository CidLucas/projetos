## 🎯 Resumo

Plataforma web para **criação, coleta e análise de questionários** com:
- **Áudio como canal de resposta nativo** (transcrição automática)
- **IA como camada de análise** (insights, correlações, relatórios)
- **Múltiplos modos de criação:** drag & drop, importação de texto, chat assistido

**Proposta:** competir em nichos BR onde Typeform é overkill e Google Forms é básico demais.
